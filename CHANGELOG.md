# Changelog

Все заметные изменения в проекте **NUBO VPN** (Android-клиент).

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Добавлено

- **Новый интерфейс** — спокойная тёмная тема без неонового свечения: палитра `#080A0F` / `#141922` / `#2563EB`, плоские карточки, обновлённая типографика.
- **Кнопка подключения** — синяя обводка и мягкая тень при активном VPN, серая — в покое; вращающаяся дуга при подключении/отключении; тактильный отклик при нажатии.
- **Главный экран** — раздельные блоки: подключение, подписка, список серверов; верхняя панель «NUBO · VPN ·» с кнопкой перехода на сайт.
- **Пинг и выбор сервера** — кнопка **«ПРОПИНГОВАТЬ»**; переключатель **«Интеллектуальный выбор»** — пингует серверы и автоматически выбирает с минимальной задержкой; автопинг при возврате в приложение и после обновления подписки (если сортировка включена).
- **Серверы** — если в названии нет флага страны, иконкой становится первый emoji из имени (например, `👑Обход глушилок` → 👑 и название «Обход глушилок»); для emoji без кода страны показ текстом, без загрузки картинки.
- **Подписка через QR** — полноэкранный сканер (CameraX + ML Kit): камера, рамка, фонарик, переключение камеры, выбор из галереи.
- **Покупка** — кнопки **«Купить на сайте»** (https://nb.nubov.org/) и **«Купить в боте»** на главном экране и в настройках.
- **Серверы** — двойное нажатие на сервер в списке: переход на главную и подключение к выбранному серверу (при смене сервера — переподключение).
- **Настройки** — переработанный экран в стиле списка с разделителями и вложенными подразделами.
- **Соединение** — отдельный раздел с подпунктами:
  - раздельное туннелирование **сайтов** (режимы «только выбранные через VPN» / «выбранные в обход», кнопка **«Применить»** для списка доменов);
  - раздельное туннелирование **приложений** (include / exclude, поиск, иконки приложений в списке);
  - **Kill Switch** — блокировка трафика при неожиданном обрыве VPN.
- **Подписка** — автообновление по интервалу (Выкл / 1 / 3 / **6** / 12 / 24 ч, по умолчанию **6 ч**); выбор интервала в раскрывающемся меню с анимацией.
- **Тема** — выбор оформления: светлая, тёмная, как в системе.
- **Логи** — просмотр и скачивание логов приложения из настроек.
- **Geo-файлы** — фоновая установка и ручное обновление geoip/geosite для маршрутизации.
- **Автопереподключение VPN** — восстановление сессии после обрыва, при возврате в приложение и при появлении сети; экспоненциальная задержка повторов (2–30 с); ручное отключение отключает автопереподключение.
- Переподключение VPN при сохранении настроек соединения, если туннель уже активен.

### Изменено

- **Верхняя панель** — убрано гамбургер-меню слева; в настройки — через нижнюю навигацию.
- **Список серверов** — компактные карточки; цвет пинга: зелёный ≤200 мс, жёлтый ≤400 мс, красный выше.
- **Список серверов** — плавнее прокрутка: emoji-флаги вместо загрузки картинок где возможно, упрощённая разметка карточек.
- Выбор сервера в списке больше не перескакивает автоматически на подключённый сервер при обновлении данных.
- Убран раздел «Резервное копирование»; вместо «Приложение» — пункт **«Логи»**.
- Улучшена видимость переключателей (`NuboSwitch`) в выключенном состоянии.
- Заголовки вложенных экранов настроек — короче, с переносом и многоточием при длинном тексте.
- Список приложений для split tunnel: больше приложений (launcher + пользовательские с INTERNET), `<queries>` в манифесте.
- Обновлён логотип приложения; убраны рекламные баннеры из ресурсов.

### Исправлено

- **QR-сканер** — стабильное распознавание кодов (переход с zxing на CameraX + ML Kit).
- Декоративные круги/водяной знак за кнопкой подключения — убраны, интерфейс стал чище.
- Режим **«Выбранные сайты в обход VPN»** (DirectBypass) — корректные правила маршрутизации и DNS.
- Split tunnel по приложениям: `strict_route`, валидация пакетов, логирование в VPN-сервисе.
- Навигация «Назад» в настройках — возврат к родительскому разделу, а не сразу на главный экран.
